# Brownloop Partner Graph

Static website files for the responsive Brownloop Partner Graph landing page.

## Host it

1. Extract the ZIP while preserving the `public/images` folder.
2. Upload the contents of the extracted folder to your static host's document root.
3. Open `index.html` locally or use your hosting provider's default site URL.

No build step or server-side runtime is required. The page loads Google Fonts from the internet and falls back to system fonts if they are unavailable.
